# Silue

一个专门为角色扮演（RP）做的 AI 聊天客户端，支持 Windows 和 iOS。还在设计阶段，没有可用的版本。

计划中的第一版：

- 导入 SillyTavern 格式的角色卡（V1/V2/V3，PNG/JSON/CHARX）、世界书、预设、正则和聊天记录
- 默认按缓存友好的顺序拼提示词，每条回复显示缓存命中和花费
- 统一的思考深度档位，自动换算成各家模型的参数
- 内置长期记忆：分层前情回顾 + 状态表
- 通过你自己的 Cloudflare 账号做端到端加密同步
- 消息里的 HTML 美化卡放进沙盒渲染

设计决定和取舍记录在 [`.agents/notes/`](.agents/notes/)。
