# Agent Note: Windows 版内置本机 MCP 接口，让 AI 直接改角色卡

Status: proposed

## Problem

开发者不写代码，平时让 AI 来改角色卡。现在的做法是通过 Tavo 的 MCP 接口：开发者桌面上的 `_mcp.js` 用 JSON-RPC 调 `tavo_character_get` / `tavo_character_update`（支持 `dryRun`），`_adv.js` 用它给万象卡加了一个「# 推进」章节。

Tavo 的这个接口开在局域网地址上，令牌只有 6 位。换到 Silue 以后，如果没有类似的接口，开发者就只能来回导出、导入卡片文件。

## Proposal

- 只在 Windows 版做。iOS 上不方便长期运行这种服务。
- 默认关闭。打开后只监听 `127.0.0.1`，令牌自动生成，至少 32 个随机字节。
- 提供角色卡、世界书、预设、正则的读写工具。
- 每个写入工具都支持 `dryRun`：只返回改动前后的差异，不真正写入。
- 写入的内容走和界面编辑同一套校验和存储代码，同步、撤销都照常生效。
- 每次写入都记一条操作日志，可以在界面上撤销。

## Alternatives considered

- **不做，靠导出导入** — 最强的理由：少一个对外开放的接口，也少一份要维护的代码。否掉的原因：开发者现在就靠这种方式改卡，没有它工作流会倒退。
- **和 Tavo 一样开放到局域网** — 最强的理由：局域网里的其他设备也能连。否掉的原因：同一个局域网里的任何设备都能尝试连接；开发者的用法是本机上的 AI 工具来连，只开 `127.0.0.1` 就够了。

## Acceptance criteria

- Claude Code 通过这个接口读出万象卡，用 `dryRun` 预览改动，再真正写入；改完之后界面上马上能看到，也能撤销。
- 从局域网里的另一台设备连接会失败。
- 令牌不对时，所有工具都拒绝执行。

## Risks

- **本机上的恶意程序**：本机上的其他程序拿到令牌就能改数据。令牌存在系统的安全存储里，界面上可以一键重新生成。
- **AI 改坏卡**：写入前有 `dryRun` 预览，写入后可以撤销。
