# Agent Note: 思考深度用统一档位，自动换算成各家的参数

Status: proposed

## Problem

开发者离开 Tavo 的第二个原因是不能调思考深度。各家控制「思考多少」的参数完全不一样：

- Claude 用 effort 或思考 token 预算
- Gemini 用 thinking budget / level
- OpenAI 用 `reasoning_effort`
- DeepSeek 只能开或关

用户在不同模型之间切换时，不应该每次都去查各家参数是什么意思。

## Proposal

- 界面上只放一个档位：关 / 低 / 中 / 高 / 最大。
- `core` 里给每家模型写一张换算表，把档位换成那家的参数。模型不支持的档位（比如 DeepSeek 没有「低」「中」），按最接近的处理，并在界面上显示实际用了什么。
- 高级设置里可以直接填那家的原始参数，填了就覆盖档位的换算结果。
- 思考过程默认折叠，可以点开看。思考内容存在本地，但发给模型的聊天历史里不带上一轮的思考内容，除非那家 API 要求必须带。

## Alternatives considered

- **每家显示自己的原生参数** — 最强的理由：没有换算误差，懂行的用户能精确控制。否掉的原因：切换模型时要重新理解每家的参数。懂行的用户可以在高级设置里填原始值，这个需求也照顾到了。

## Acceptance criteria

- 用 [标准答案测试](../testing/2026-10-19-golden-prompt-tests.md) 固定：每家模型的每个档位，请求里的思考参数都和换算表一致。
- 填了原始参数之后，请求里用的是原始参数。

## Risks

- **参数格式会变**：各家 API 改了思考参数的格式，换算表就要跟着改。标准答案测试能发现请求内容的变化，但发现不了 API 那边的变化，需要定期对照官方文档。
- **历史里带不带思考内容**：各家规则不一样，具体规则要在实现时按官方文档逐家核对。这篇笔记里没有核对过。
